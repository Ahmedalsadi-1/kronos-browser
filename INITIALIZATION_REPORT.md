## 🏗️ Architecture & Components

The project is a multi-project monorepo focused on AI-driven browser automation and desktop orchestration.

### 1. Kronos Agent (formerly Bytebot/Kronbot)
- **Backend (`kronbot/packages/bytebot-agent`)**: A NestJS application that orchestrates AI workflows and handles LLM integrations.
- **Frontend (`kronbot/packages/bytebot-ui`)**: A Next.js management interface for agents and virtual desktop viewing.
- **Shared Library (`kronbot/packages/shared`)**: Common types and utilities used across the agent stack.
- **Desktop Service (`kronbot/packages/bytebotd`)**: Manages the virtual Ubuntu/XFCE desktop environment via Docker.

### 2. BrowserOS
- **Agent Monorepo (`kronbot/kronosOS/packages/browseros-agent`)**: A Bun-based project containing:
    - **MCP Server**: Implements the Model Context Protocol for tool discovery.
    - **Chrome Extension Bridge**: A controller extension that enables deep browser interaction.
- **Chromium Fork (`kronbot/kronosOS/packages/browseros`)**: A patched version of Chromium optimized for AI agents.

### 3. Rebranding Status
The ecosystem is transitioning from "Bytebot" to "Kronos Agent" and "Factifai" to "Kronos Desktop". Root-level documentation reflects this, though many internal package names still use the legacy branding.
