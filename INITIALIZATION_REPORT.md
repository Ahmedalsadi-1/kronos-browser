## 💡 Notes for Developers
- **Runtime Consistency**: Use **Bun** for everything inside `browseros-agent`. Use **NPM** for `kronbot/packages`.
- **Database**: Agents expect a PostgreSQL instance at `postgres:5432` as per `.env.example`.
- **Shared Library**: Always build `kronbot/packages/shared` first if changes are made, as other packages depend on its `dist/` folder via relative file paths.
