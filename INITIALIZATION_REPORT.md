## 📋 Overview
The KRONOS-OS ecosystem has been successfully initialized. This monorepo contains multiple interconnected products focused on AI-powered browser automation and desktop orchestration.

## 🏗️ Architecture & Components

### 1. Bytebot Ecosystem (`kronbot/packages/`)
- **@bytebot/shared**: Core utilities and types shared across all Bytebot packages.
- **bytebot-agent**: AI agent service powered by NestJS and Prisma.
- **bytebot-agent-cc**: AI agent service (Claude Code integration) powered by NestJS and Prisma.
- **bytebot-ui**: Next.js-based management dashboard for agents.
- **bytebotd**: Daemon service for desktop orchestration, using `nut-js` and `uiohook-napi`.

### 2. BrowserOS Agent (`kronbot/kronosOS/packages/browseros-agent/`)
- **@kronos/server**: Bun-based MCP (Model Context Protocol) server for browser automation.
- **@kronos/assistant**: Chrome extension for AI interaction.
- **@browseros-ai/agent-sdk**: SDK for building browser automation tools.

### 3. BrowserOS Engine (`kronbot/kronosOS/packages/browseros/`)
- Python-based component related to the Chromium fork and orchestration.
