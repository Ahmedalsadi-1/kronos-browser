## 🏗️ Project Architecture & Components

The Kronos-OS ecosystem is a multi-project monorepo (nested) containing several AI-driven browser and desktop automation platforms.

### 1. Bytebot (Kronbot) - AI Desktop Agent
Located in `kronbot/packages/`. A NestJS/Next.js based platform for desktop automation.
- **bytebot-agent**: Core AI orchestration service.
- **bytebot-agent-cc**: Computer control agent.
- **bytebot-ui**: Next.js management dashboard.
- **bytebotd**: Desktop daemon for computer-use actions.
- **shared**: Shared utilities and types.

### 2. BrowserOS - Intelligent Browser Agent
Located in `kronbot/kronosOS/packages/browseros-agent`. A Bun-powered MCP server and ecosystem.
- **apps/server**: MCP server for browser automation.
- **apps/agent**: AI browser assistant (extension).
- **apps/controller-ext**: Bridge extension for browser control.
- **packages/agent-sdk**: SDK for building browser agents.

### 3. Pre-built Artifacts
- **kronbot/BrowserOS-agent/**: Contains pre-built Chrome extension files (manifest.json, background.js, etc.).
- **kronos-os/built-extensions/**: Contains pre-built macOS application wrappers for extensions.

### 4. Placeholder Directories
Several root-level directories exist as empty placeholders or legacy references:
- `BrowserOS/`, `desktop/`, `EdgyArc-fr/`.
- `website/`: Contains a static `index.html`.
