## 🏗️ Ecosystem Overview
The Kronos OS ecosystem is a multi-layered platform for AI-driven browser automation and orchestration. It consists of three primary domains: Orchestration (NestJS), Browser Automation (Bun/TypeScript), and Management (Next.js).

### 1. Orchestration & Agents (`kronbot/packages/`)
- **`bytebot-agent`**: Main NestJS agent for task orchestration.
- **`bytebot-agent-cc`**: Specialized agent (Claude Code compatible).
- **`bytebotd`**: Background daemon for computer-use and input tracking.
- **`bytebot-llm-proxy`**: LiteLLM-based proxy for multi-provider support.
- **`shared`**: Common utilities and types used across all packages.

### 2. Browser Automation (`kronbot/kronosOS/packages/`)
- **`browseros-agent`**: A Bun-powered MCP server that bridges the browser extension to the LLM.
- **`browseros`**: Chromium fork with native AI integrations.

### 3. Management UI (`kronbot/packages/bytebot-ui`)
- A Next.js dashboard for monitoring agent status, tasks, and real-time VNC browser views.
