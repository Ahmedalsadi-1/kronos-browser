# KRONOS-OS Ecosystem Summary

## Project Overview
KRONOS-OS is a comprehensive monorepo focused on AI-powered browser automation and desktop agent orchestration. It represents a rebranding and evolution of the "Bytebot" and "Factifai" ecosystems.

## Core Components

### 1. Kronbot Orchestration Platform (`kronbot/`)
- **Location**: `kronbot/packages/`
- **Architecture**: NestJS backend, Next.js frontend, Prisma ORM.
- **Key Services**:
  - `bytebot-agent`: Orchestrates AI tasks and desktop actions.
  - `bytebot-ui`: Management dashboard for monitoring and controlling agents.
  - `shared`: Common utilities and types.
- **Tech Stack**: TypeScript, Node.js, PostgreSQL, Tailwind CSS 4.

### 2. BrowserOS Agent (`kronbot/kronosOS/packages/browseros-agent`)
- **Description**: A Bun-based MCP (Model Context Protocol) server and browser extension bridge.
- **Functionality**: Provides tools for direct CDP-based browser interaction and extension-based control.
- **Tech Stack**: Bun, TypeScript, WXT (Web Extension Toolbox).

### 3. BrowserOS Chromium Fork (`kronbot/kronosOS/packages/browseros`)
- **Description**: A customized fork of Chromium designed for deep integration with AI agents.

### 4. Shared Utilities (`kronbot/packages/shared`)
- **Description**: Provides centralized logic for computer actions, constants, and types used across the ecosystem.

## How to Run
### Local Development
- **UI**: `cd kronbot/packages/bytebot-ui && npm run dev` (Port 9992)
- **Agent**: `cd kronbot/packages/bytebot-agent && npm run start:dev` (Port 9991)
- **MCP Server**: `cd kronbot/kronosOS/packages/browseros-agent && bun run start:server` (Port 9100)

### Docker Deployment
- Use the provided configuration in `kronbot/docker/docker-compose.yml` to launch the entire stack.
